# 🛍️ Consumer Shopping Behavior Analysis

An end-to-end **Data Analytics** project that analyzes retail consumer shopping behavior using **Python, PostgreSQL, SQL, and Power BI**. The project focuses on uncovering customer purchasing patterns, product performance, sales trends, and business insights to support data-driven decision-making.

---

## 📌 Project Objective

The objective of this project is to analyze consumer shopping behavior and answer key business questions related to customer demographics, purchasing habits, product performance, discounts, subscriptions, shipping preferences, and seasonal trends.

---

## 🛠️ Tech Stack

- Python (Pandas, NumPy)
- PostgreSQL
- SQL
- SQLAlchemy
- Psycopg2
- Power BI
- Git & GitHub
